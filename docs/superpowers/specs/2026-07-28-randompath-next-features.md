# RandomPath 下一批新功能 · 设计方案

> 🦸‍♂️ 春日部防卫队出品 · 2026-07-28

## 范围

三个功能，按实现复杂度排序：

| 功能 | 复杂度 | 说明 |
|------|--------|------|
| C2 附近起点模式 | ⭐ 小 | 户外自动以当前位置出发 |
| B2 路线属性标签 | ⭐⭐ 中 | 自然/人文/骑行三类标签自动识别 |
| C3 骑到某处模式 | ⭐⭐⭐ 大 | 选目的地自动生成来回路线 |

---

## C2：附近起点模式

### 触发逻辑

`ExploreView.onMounted` 中 GPS 定位成功后：
1. 算当前坐标离"家"的直线距离
2. > 2km → 自动把起点设为当前位置，首页 GPS 条显示 `📍 当前位置 · 离家 X.Xkm`
3. ≤ 2km → 正常显示家地址

### 手动切换

GPS 条右侧加一个小按钮 `🏠`，点了切回"家"地址。再次 GPS 定位又可以切回来。

### 改动范围

只改 `ExploreView.vue`——初始化逻辑 + GPS 条 UI。路线引擎、API 层不变。

## B2：路线属性标签

### 数据来源

| 类别 | 标签示例 | 数据来源 |
|------|---------|---------|
| 🟢 自然 | 沿河骑行、林荫道、湖边、盘山路 | 高程剖面 + 地形判断 |
| 🟣 人文 | 路过古寺、经过古镇、途经 XX 景点 | 高德沿途 POI 搜索 landmark |
| 🟠 骑行 | 爬坡王、平路巡航、弯道多、红绿灯少 | 路线几何数据 + 高德路口数据 |

### 实现方式

路线生成完成后，在 `useRouteContext` 中新增 `analyzeRouteTags(segments, waypoints)` 函数：

**自然类标签（离线，不需要 API）：**
- 爬坡王：`uphillSections` 总爬升 ≥ 200m 或单段坡度 ≥ 8%
- 平路巡航：总爬升 < 50m 且距离 > 10km
- 沿河骑行：路线点与高德水系 POI 匹配（复用 `searchPOIs`）
- 盘山路：弯道密度高 + 爬升大

**人文类标签（需要 API，在 `loadContext` 时一并获取）：**
- 沿路线采样点搜索 `types="060400|080000|110000"` (风景名胜/寺庙/古镇)
- 匹配到的 POI 名作为标签显示

**骑行类标签（离线）：**
- 弯道多：polyline 连续转角 > 30° 的次数 / 路线总长
- 红绿灯少：高德路口 POI 搜索

### 展示位置

结果页 `quality-tags` 区域，用颜色区分三类标签。

### 改动范围

- `useRouteContext.js`：新增 `analyzeRouteTags`
- `ResultView.vue`：标签区域颜色分类
- `RouteThumbnail.vue`：（可选）人文 POI 标注在 Canvas 上

## C3：骑到某处模式

### 交互流程

1. 首页加第三种模式入口——`🎯 骑到某处`（复用 SceneCards 组件，加第四张卡片）
2. 点卡片 → 弹出目的地搜索框（类似起终点地址搜索）
3. 输入地名 → `geocode` 获取坐标 → 显示预估单程距离
4. 用户确认 → 引擎执行

### 路线生成逻辑

两次调用现有 `tryGenerateRoute`：

```
去程：起点(家/当前位置) → 目的地
返程：目的地 → 起点(家/当前位置)
```

拼接策略：
- 去程 waypoints 正常生成
- 返程 waypoints 尽量避免和去程重合（方向不同、途经点不同）
- 将两段 segments + waypoints 合并为一个 route 对象
- 总距离 = 去程 + 返程，总时长 = 去程 + 返程

### 目的地预估

用户输入目的地后、点出发前：
1. 调高德骑行路径规划 API（`fetchBicyclingRoute`）获取 "起点→目的地" 的单程距离
2. 显示在卡片上：`📍 雁塔区 → 秦岭脚下 约 28km(单程)` + `来回预计 56km · 3.5h`
3. 用户确认后走正式生成流程

### 结果展示

结果页标题改为 `📍 去 XX + 回来`，中间标注目的地位置，分段详情区分去程段和返程段。

### 改动范围

- `ExploreView.vue`：新增模式状态、目的地搜索 UI
- `SceneCards.vue`：加第四张卡片
- `useRouteEngine.js`：新增 `generateRoundTrip` 或直接在 ExploreView 中调两次 `tryGenerateRoute`
- `ResultView.vue`：适配来回路线展示
